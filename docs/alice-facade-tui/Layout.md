# 7. 功能用例与 TUI 布局（单线切割 + 向上顶出补全版）
基于 **JLine 3** 实现**纯硬编码、无画面抖动**的三层单线分割布局，整体采用静态分割线划分区域，结合原生补全机制实现向上弹出选择菜单，分区边界固定、渲染高效。

## 7.1 沉浸式三看板常态布局（TAO Standard Mode）
通过两条统一单线 `───` 将终端垂直划分为**三大固定区域**，日志内容向上滚动，**最后三行永久锁定**：上分割线、居中输入框、底部计费状态栏，分区规则强固定。

布局示例：
```
 alice v0.60.0                                                                                                     
----------------------------------------------------------------------------------------------------------------
 [T Thought]: 监测到 uncommitted 悬空状态，自动触发双式记账平衡等式校验。
 [T Thought]: 校验断言 ∑Debit = ∑Credit 失败，潜在风险指向 Double-Entry 借贷不平衡。
 [A Action ]: 调用本地 Bash 执行器: $ gradle :cland-chainpay:test --tests "AccountLedgerTest"
 [O Observe]: BUILD SUCCESSFUL in 3s (1 test passed)
 [T Thought]: 单元测试断言通过，判定悬空流水为 Clearing 延迟，账目底层等式实质守恒。
 [T Thought]: 审计链路闭环。准备向用户输出白盒分析报告。
                                                                                                                
────────────────────────────────────────────────────────────────────────────────────────────────────────────────
 > /_                                                                           <- 居中输入区域
────────────────────────────────────────────────────────────────────────────────────────────────────────────────
 💰 Cost: $0.041 | 📊 Speed: 125 t/s | 🧠 Model: deepseek-v4-flash • medium | 🔌 Active Tool: cland-pay-mcp     
```

区域划分说明：
1. **上方滚动区**：业务日志、思考/动作/观测流输出，内容正常向上滚动；
2. **中间输入区**：被两条分割线包裹，输入提示符固定居中，位置永不偏移；
3. **底部状态栏**：计费、速率、模型、工具等核心指标，全程固定在页面最底端。

## 7.2 `/model` 指令：输入框向上展开补全列表（AutoComplete Popup Mode）
在输入框内输入 `/model ` 后，按下 `Tab` / 上下方向键，JLine 3 原生 `AUTO_MENU` 拦截渲染逻辑，**在首条分割线下方、输入框上方向上顶出选择抽屉**。
- 弹窗仅覆盖上方滚动区末尾内容；
- 两条分割线、输入框、底部计费状态栏**完全静止**，无位移、无重绘抖动；
- 选中项回车确认后，弹窗即时销毁，上方滚动区内容无缝复位。

布局示例：
```
 [A Action ]: 调用本地 Bash 执行器: $ gradle :cland-chainpay:test --tests "AccountLedgerTest"
 [O Observe]: BUILD SUCCESSFUL in 3s (1 test passed)
 
 [🔼 SELECT MODEL] ─────────────────────────────────────────────────────────────────────────────────────────────
    deepseek-v4-flash • medium  (当前使用)
 👉 deepseek-v4-reasoning • deep (按 Tab/上下键轮转选中)
    gpt-4o-mini
    claude-3.5-sonnet
────────────────────────────────────────────────────────────────────────────────────────────────────────────────
 > /model deep|                                                                 <- 居中输入区域（内容联动回显）
────────────────────────────────────────────────────────────────────────────────────────────────────────────────
 💰 Cost: $0.041 | 📊 Speed: 125 t/s | 🧠 Model: deepseek-v4-flash • medium | 🔌 Active Tool: cland-pay-mcp     
```

## 🧠 架构设计核心优势
1. **分区边界绝对固定**
   视觉分割线作为硬边界，日志、输入、状态三大模块彻底解耦，终端呈现标准化仪表盘样式，视觉秩序统一。

2. **原生向上弹窗机制**
   依托 JLine 3 原生 `Upward Popup` 特性，因输入区紧贴底部状态栏，补全菜单强制向上展开，交互逻辑对齐主流高级 CLI 体验，无需额外自定义弹窗逻辑。

3. **极致低开销、零闪烁**
   摒弃全局定时全屏刷新方案，仅在日志更新、计费数据变动时执行**单行精准擦除/重绘**，渲染开销极低，对服务器性能无额外损耗。

该三层单线分割架构最大化复用 JLine 3 原生能力，兼顾视觉规范、交互体验与运行性能。
