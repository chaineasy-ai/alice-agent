# 7. 功能用例与 TUI 布局（Lanterna 硬编码 + 增量渲染版）
基于 **Lanterna 3.1.3** 实现**纯硬编码、无画面抖动**的三层单线分割布局，整体采用静态分割线划分区域，分区边界固定、渲染高效。

> **实现说明**: TUI 渲染层完全基于 Lanterna（`com.googlecode.lanterna`），不依赖 JLine 3。
> JLine 3 依赖已从 `alice-facade-tui` 模块中移除（2026-06-12），仅用于 CLI Chat 模式（`alice-facade-cmd`）。
> - 输入处理：`ScreenManager.handleInput(KeyStroke)` 接收 Lanterna 键盘事件
> - 输入组件：`InputComponent` 自定义 Lanterna 组件（非 JLine LineReader）
> - 补全菜单：暂未实现，后续可用 Lanterna 原生能力或自定义弹窗

## 7.1 沉浸式三看板常态布局（TAO Standard Mode）
通过两条统一单线 `───` 将终端垂直划分为**三大固定区域**，日志内容向上滚动，**最后三行永久锁定**：上分割线、居中输入框、底部状态栏，分区规则强固定。

当前实现对应 `TuiLayout` 类，见 [DESIGN.md §7.1](./DESIGN.md)。

布局示例：
```                                                                                               
┌─ Alice Agent v1.0 ─ Model: gpt-4o-mini ─ Status: Running ────────────────────┐
│ [Agent]   思考中: 分析用户输入...                                              │
│ [Thought] step 1: 解析用户意图                                                 │
│ [Action ] 调用工具: bash (gradle test)                                         │
│ [Observe] BUILD SUCCESSFUL in 3s (1 test passed)                              │
│ [Thought] step 2: 审计结果闭环                                                 │
│ [Agent]   执行结果已准备输出                                                    │
│                                                                                │
├────────────────────────────────────────────────────────────────────────────────┤
│ > /_                                                                          │
├────────────────────────────────────────────────────────────────────────────────┤
│ F1:帮助 │ F5:停止 │ F10:退出 │ Tab:切换焦点 │ PgUp/PgDn:翻页                 │
└────────────────────────────────────────────────────────────────────────────────┘
```

区域划分说明（对应 `TuiLayout` 布局管理器）：
1. **HeaderComponent**（顶部标题栏）：单行展示 Agent 名、当前模型、运行状态
2. **ChatComponent + ThoughtComponent**（左侧日志区 + 右侧思考流）：内容正常向上滚动，支持 PgUp/PgDn 翻页
3. **InputComponent**（输入区）：被两条分割线包裹，输入提示符 `> ` 固定，位置永不偏移
4. **FooterComponent**（底部快捷键提示栏）：F1 帮助 / F5 停止 / F10 退出 / Tab 切换焦点

> 当前实现状态：
> - ✅ 静态三栏布局（分割线 + 固定输入区 + 底部提示）
> - ✅ 焦点切换（Tab 轮转：INPUT → CHAT → THOUGHT → INPUT）
> - ✅ 方向键滚动 / 翻页 / Ctrl+Q 退出
> - ✅ 历史导航（上下方向键）
> - ⏳ `/model` 补全弹窗（待实现，见 §7.2）

## 🧠 架构设计核心优势
1. **分区边界绝对固定**
   视觉分割线作为硬边界，日志、输入、状态三大模块彻底解耦（由 `TuiLayout` 统一管理），终端呈现标准化仪表盘样式，视觉秩序统一。

2. **Lanterna 原生输入处理**
   `ScreenManager` 通过 `screen.readInput()` 监听 `KeyStroke`，无需第三方输入库。`InputComponent` 基于 `TextGraphics` 自绘，支持光标、历史、焦点高亮。

3. **增量渲染、零闪烁**
   采用脏标记（`markDirty()`）机制，仅在组件数据变更时执行重绘。渲染循环（`FRAME_INTERVAL_MS=50ms`）无需全局全屏刷新，渲染开销极低。

4. **模块化组件体系**
   所有 UI 组件继承 `Component` 抽象基类，通过 `TuiLayout.getComponents()` 统一管理。新增组件只需实现 `draw(TextGraphics)` 并注册到布局即可。

该三层分割架构基于 Lanterna 4.1 万行级工业终端框架，兼顾视觉规范、交互体验与运行性能。
