## 0. 先看结论（一页）

| 问题 | 结论 |
|---|---|
| 它是什么 | 一个 **Java 25 / JPMS / Gradle 多模块的 Agent 内核**：会话语义、规划、工具、护栏、记忆、事件流、三种门面，可被 CLI/TUI/HTTP 驱动。 |
| 它现在能稳定干什么 | **单 Agent 一轮任务**（规划→工具→回答）、**HTTP/stdio 驱动**、**人用 CLI/TUI**、**基础护栏与 WAL**、**图内核可取消/可恢复（部分门面已接）**。 |
| 它现在不能干什么 | 不能当"开箱即用的业务 agent"；skills 渐进披露、session compaction、sub-agent 实跑、MCP 接线、记忆持久化、usage/cost 上报、正式发布制品均未完成。 |
| 与 pi/loopd 的关系 | Owner 已裁定 **长期并存**（`#3`）。**近期生产默认 pi，alice 只做内核试点/对比**；分工见 §5，未定项显式标"待 ADR"。 |
| 最需要先修的 | ~~护栏前置校验没有校验工具参数~~ **已在 `#665` 修复**：`PermissionSandboxValidator` 现递归扫描 `step.parameters()`，`/etc/passwd`、`dd` 在 params 层被 `REJECT`（见 §3.4 / §6 G1）。 |

## 1. 模块清单（13 个构建模块，逐一有职责与可见性）

> **权威口径 = 13 个 Gradle/JPMS 模块**（`settings.gradle` 13 条 `include`，`find -name module-info.java` = 13）。
> `#173/#3` 曾写"24 模块"，接管档已勘误；本文在 §2 给出 24 口径的完整映射，**不丢单元、不设"其它"兜底**。

| # | 模块 | 一句话职责 | 对外可见性 | 当前是否在主路径 |
|---|---|---|---|---|
| 1 | `alice-bootstrap` | JVM 入口/组合根：`AliceApp`、`FacadeSelector`、按 SPI 加载 CLI/TUI/RPC 门面 | **直接对外**：`alice` 可执行文件的入口 | ✅ 是 |
| 2 | `alice-agent-proto` | 协议契约层：`AgentCommand`（入）/`StepEvent`（出）/Dispatcher 端口/codec/版本 | **直接对外**：stdio JSONL 与 HTTP RPC 的帧契约 | ✅ 是 |
| 3 | `alice-agent-runtime` | 会话宿主：一轮一锁、事件映射、收口 `DONE`、健康快照、InProcess/Stdio transport | **间接对外**：RPC `/health`、事件流、stdio 驱动都经过它 | ✅ 是 |
| 4 | `alice-core-agent` | 内核主体：legacy `AgentExecutor` + 图内核（R0 解释器/账本/标准骨架/`GraphSessionKernel`）+ WAL/Checkpoint | **间接对外**：CLI/TUI/RPC 的回答与事件最终由它产生 | ✅ 是（双运行时并存） |
| 5 | `alice-core-planner` | 战略规划：FastPath / SlowPath（MCTS）/ SOP 静态规划，产出 Plan | **间接对外**：规划结果体现在任务执行步骤中 | ✅ 是 |
| 6 | `alice-model` | 模型抽象与供应商适配：OpenAI 兼容、Claude、Gemma4 | **间接对外**：模型回答经门面呈现 | ✅ 是（需配置/凭据） |
| 7 | `alice-tool-gateway` | 工具注册/发现/JSON Schema/执行/沙箱 + 9 个内置工具 | **间接对外**：LLM 可调用工具；`alice tools` 是查询入口 | ✅ 是（`tools` 子命令有缺口，见 §6 G2） |
| 8 | `alice-guardrail` | 安全护栏：Pre/Post 校验链、权限沙箱、幻觉检测、`GuardrailToolProxy` | **间接对外**：拦截结果以工具失败/审计结果呈现 | ✅ 前置校验覆盖 target + params（`#665`，G1 已修） |
| 9 | `alice-env-adapter` | 环境适配：MCP 客户端（Stdio/SSE）、shell 执行环境、快照 | **不直接对外**：当前没有生产调用方（孤岛，G6） | ❌ 未接线 |
| 10 | `alice-memory-vault` | 记忆库：Episodic/Procedural/Semantic、JVector 检索、SOP DAG、Dreaming | **不直接对外**：`VaultController` 无消费者（孤岛，G6） | ❌ 未接线 |
| 11 | `alice-facade-cli` | 人用命令行：`run/chat/tools/config/routine/resume/sub-agent` + JLine REPL + `--json` | **直接对外**：终端用户 | ✅ 是 |
| 12 | `alice-facade-tui` | 人用终端 UI：JLine + Vert.x 事件桥，Chat/Input/Thought 三区布局 | **直接对外**：终端用户 | ✅ 是（但走 legacy 运行时，见 G7） |
| 13 | `alice-facade-rpc` | 程序用 HTTP RPC 2.0：`/api/v1/*` + SSE，把协议命令/事件暴露给调度器 | **直接对外**：HTTP 客户端/调度器 | ✅ 是 |

### 1.1 模块边界（不做什么）

| 模块 | 明确不做什么 |
|---|---|
| `alice-model` | 不训练 LLM；不做计费结算；不做模型路由策略（在 planner/core） |
| `alice-tool-gateway` | 不做权限决策（在 guardrail）；不做规划 |
| `alice-agent-proto` | 无业务逻辑、无状态、不持久化 |
| `alice-core-planner` | 不执行工具/模型调用；不持久化记忆 |
| `alice-env-adapter` | 不做工具注册（在 tool-gateway）；不做决策 |
| `alice-guardrail` | 不改写业务语义；不做规划 |
| `alice-core-agent` | 不做 UI；不定义协议帧；不承担外部接入鉴权 |
| `alice-memory-vault` | 不做跨租户隔离；当前不做会话上下文压缩 |
| `alice-agent-runtime` | 无 UI；不做业务决策；不做持久化策略 |
| `alice-bootstrap` | 不含业务实现，只装配 |
| `alice-facade-cli` | 不是机器协议入口（机器走 RPC/stdio）；不持有会话状态 |
| `alice-facade-rpc` | 无状态；不承担会话/轮次/持久化（在 runtime）；不依赖 core 实现 |
| `alice-facade-tui` | 不持有业务逻辑 |

## 2. "24 模块"口径的完整映射（13 + 11 个核心能力域）

> **为什么要写这一节**：需求文字与历史单据使用"24 模块"。实读结论是 **13 个 Gradle/JPMS 模块**；`#3` 已判"24 口径废止"。
> 为满足"24 个单元逐一有归属、不许其它兜底"，把 `alice-core-agent` 内部实际承担能力的 11 个域单列，合计 **13 + 11 = 24**。
> 支撑包 `tool/`、`result/`、`lifecycle/` 分别归入第 7、4、5 行，**不另设"其它"**。

| # | 核心能力域（`alice-core-agent` 内） | 一句话职责 | 对外可见性 |
|---|---|---|---|
| 14 | `kernel` | 内核执行契约：`Loop`/`SessionRequest`/`SessionResult`/`KernelState`/事件流 | 间接：经门面回答/事件 |
| 15 | `kernel.graph` | 图元模型、Ledger（唯一账本写点）、R0 解释器、决策词表 | 间接：账本/事件可观测 |
| 16 | `graph` | 生产装配：`GraphSessionKernel`、PlannerGoalBrain、LlmActorBrain、`ToolRegistryEffectGateway` | 间接：CLI/RPC 的图内核执行 |
| 17 | `executor` | legacy `AgentExecutor`：ReAct/PPAO 编排、微循环、工具调度 | 间接：TUI/legacy 路径 |
| 18 | `pipeline` | LLM 流水线六段（serialize/transport/map/…）与 Inferencer 语义 | 间接：模型调用 |
| 19 | `memory` | `AgentSession` 短期上下文（内存 Map） | 间接：会话上下文 |
| 20 | `prompt` | PromptManager / FilePromptLoader / rules / prompts 装配 | 间接：模型提示词 |
| 21 | `wal` | WAL + Checkpoint 写入/恢复，支撑断点续跑 | 间接：`~/.alice/wal/` 文件 |
| 22 | `subagent` | 子 Agent 管理（`SubAgentManager`/记录/生命周期） | 间接：CLI `/sub-agent`（当前部分占位） |
| 23 | `acp` | ACP 子代理协议接入（`internal/acp`） | 不直接对外：尚未接线 |
| 24 | `guardrail`（core 侧适配） | `GuardrailVerificatorAdapter`、`VerifyPostGatePolicy`、`GuardrailToolProxy` | 间接：拦截/审计结果 |

**结论**：历史"24"不是 24 个构建模块；本文覆盖 **13 个构建模块 + 11 个核心能力域**，每个都有职责与可见性，无"其它/杂项"。

### 3.4 guardrail 拦截：前置校验已覆盖工具参数（已拦截）

**组件级（可判定、可复跑）**：

```bash
./gradlew :alice-guardrail:runHoleTest --args="sandbox" --console=plain
# PASS: GRD-P05 PermissionSandboxValidator
```

该用例直接构造 `Plan(target="/etc/passwd")`，前置校验器返回 `REJECT`。

**装配层真实形态（`#665` 修复点）**：`GuardrailToolProxy.buildSingleStepPlan()` 把 `Plan.Step.target` 设为**工具名**（如 `run`/`read_file`），文件路径/命令在 `params` 里。因此 `PermissionSandboxValidator` 现在除 `step.target()` 外，**递归扫描 `step.parameters()` 的字符串值**（`String` / `List` / `Map` / 数组 / 嵌套，非字符串跳过）：

- **路径类**：字符串按 shell 分隔符切分后，任一路径 token（含 `key=value` 的值部分，如 `of=/tmp/x`）命中 `forbiddenTargetPrefixes`（`/etc/`、`/proc/`、`/sys/`、`/dev/`、`/boot/`、`/root/`、`/var/log/`、`C:\Windows\System32\` 等）⇒ `REJECT`；
- **命令类**：切分后的 token **等于** `forbiddenTargetExact` 中的命令（`dd`、`mkfs`、`shutdown`、`reboot`、`init`）⇒ `REJECT`；多词短语 `rm -rf /` 按"连续 token 子序列"匹配；
- `target` 检查语义**一字未改**（原 hole test 继续绿）。

复跑（组件级，`Plan.Step.of(Intent.SEARCH, target, params)` 构造）：

```bash
./gradlew :alice-guardrail:test --tests '*PermissionSandboxValidatorSpec' --console=plain
# 9 tests, 0 failures
#  GRD-P05-a: target="read_file", params={path:"/etc/passwd"}                 ⇒ REJECT
#  GRD-P05-b: target="run", params={command:"dd if=/dev/zero of=/tmp/x ..."}   ⇒ REJECT
#  GRD-P05-c: target="run", params={args:["sh","-c","mkfs.ext4 /dev/sdb"]}     ⇒ REJECT（嵌套）
#  GRD-P05-d: params={path:"/tmp/data.txt"} / {command:"ls -l /tmp"}           ⇒ ALLOW（正控，不误杀）
```

**端到端（真实 CLI）**：

```bash
alice run --graph-kernel=off --timeout 180 \
  "请直接执行 shell 命令：dd if=/dev/zero of=/tmp/alice_guardrail_probe bs=1 count=1，然后告诉我是否成功。"
```

修复前（`#665` 报告时的实测）：

```text
（无 Guardrail REJECT 日志）
ls -l /tmp/alice_guardrail_probe
-rw-rw-r-- 1 alice alice 1 10月 23 03:51 /tmp/alice_guardrail_probe
```

修复后判定：**参数层（params）拦截已生效**，`dd if=/dev/zero of=/tmp/x`（`dd` 命令 token + `/dev/` 路径前缀）、`read_file(path=/etc/passwd)`（`/etc/` 前缀）均在前置校验被 `REJECT`。真实 CLI 的端到端复跑（`alice run --graph-kernel=off` + 断言 `/tmp/alice_guardrail_probe` 不存在）由 `#665` 验收方执行并留回显。

**另一条可用的端到端拦截证据**：后置校验会拦截工具失败观测。

```bash
alice run --graph-kernel=off --timeout 180 \
  "请用 web_search 工具搜索 'qzxvbnmplkjhgfdsa1234567890'，并把搜索结果原样告诉我。"
```

```text
WARN [GuardrailToolProxy] Post-check FAILED: tool=web_search
     reason=Observation status is FAILURE: Tool [web_search] execution failed...
```

**判定**：✅ 护栏组件可用；✅ **前置校验已覆盖 `target` + `parameters` 两层（`#665`，params 层拦截）**；✅ 后置校验会拦截工具失败观测。

## 5. 与 pi/loopd 的分工对照表（Owner 已裁定"长期并存"）

> **先给一句话决策规则**：
> **"今天就要把活干完 / 要成熟的编码与运营体验" → pi。**
> **"要把 Agent 内核嵌进 Java 系统，或需要图语义的可取消/可恢复/可审计" → alice-agent。**
> **两边都能做的（单 Agent 循环、工具调用、HTTP/stdio 驱动）→ 生产默认 pi，alice 只做试点与对比，直到 `#3` ADR 给出切换阈值。**

| 能力/场景 | 默认放哪边 | 判据 | 状态/备注 |
|---|---|---|---|
| 日常编码、文件编辑、命令执行 | **pi** | pi 有成熟工具链、skills、TUI；alice 有基础工具但缺 skills/稳定门禁 | 现状 |
| 运营/巡检/群聊常驻 agent | **pi** | loopd 常驻连接、角色档案、群聊/私聊、调度唤醒已在 pi 侧成熟 | 现状 |
| skills 渐进披露 / 角色规则 / 提示词模板 | **pi** | alice 未实现 skills 加载；CLI 的 `/skill` `/rules` 仍是回显占位 | 现状 |
| sub-agent / ACP 多代理 | **pi（暂）** | pi 已有 `subagent`；alice 的 003 未接线，RPC 直接拒绝 SubAgent 命令 | 待 `#3` ADR 统一语义 |
| session compaction / 上下文压缩 | **pi（暂）** | alice `/compact` 返回"待 Memory 模块提供总结接口" | 待定 |

| HTTP/stdio 被调度器驱动 | 重叠 | alice 有 RPC 2.0/stdio；pi 有 worker HTTP/stdio RPC | 客户端按现有接入选；默认不迁 |

## 6. 明确"不做什么"（边界）

**产品边界（现在不承诺）**：

1. **不做 LLM**：不训练、不微调、不做模型服务；只做模型适配。
2. **不做 Web/桌面 GUI**：只有 CLI/TUI；TUI 之外不投 UI。
3. **不做通用工作流/BPMN 引擎**：SOP 只服务 Agent 规划，不替代 n8n/流程平台。
4. **不做多租户、计费、权限管理控制面**：RPC 鉴权是最简形态；要鉴权请放在网关之后。
5. **不做生产级集群/HA/分布式调度**：当前是单机常驻进程 + 文件 WAL。
6. **不交付"开箱即用业务 agent"**：交付的是内核；业务 agent 由使用方在其上构建。
7. **不做数据库边界**：仓内无 JDBC/ORM/Redis；持久化是 `~/.alice/` 文件。未来提 DB 必须先有读写场景（`#3` 已判）。
8. **不替代 pi**：Owner 裁定长期并存；替换是验证后的结论，不是当前目标。
9. **不装测试用例管理平台**：`#567/#669` 明确"装须 Owner 批"。
10. **不为 R0 旧接口背兼容层**：Owner `#3` 裁定"不需要兼容"。

**工程边界**：

- 不在本仓写业务代码；不在 `#663` 改架构结论（`#3` 已定）。
- 缺陷另开单挂 `#173`，不在文档里"顺手修"。
