# 2026-09-19 发布清单：协议层转正与门面收敛

> **评审结论（本次拍板）**
> 1. **协议层 = `alice-agent-proto`**（原 `alice-agent-command`，**改名已完成 2026-09-19**）：对内/对外同一份契约
>    （命令 + 事件 + 分发端口 + codec + 版本）。
> 2. **门面按"对端"分**：UI 适配（人：`alice-facade-cli` + `facade-tui`）｜ 协议适配（程序：stdio/HTTP/ACP）；
>    `docs/alice-facade-web` 的 HTTP RPC 2.0 → **`alice-facade-rpc`**。
> 3. **传输可插拔、宿主不出流**：`InProcess / StdioJSONL / HTTP+SSE / ACP` 只是 transport；`System.in/out` 不进宿主。
>

## 附录 A：StepEvent v1 字段草案

```json
{
  "v": 1,
  "type": "THOUGHT | TOOL_CALL | TOOL_RESULT | OBSERVE | SUMMARY | DONE | ERROR",
  "sessionId": "雪花ID",
  "traceId": "t<对象>-<epoch>",
  "seq": 12,
  "ts": "2026-09-19T12:00:00+08:00",
  "payload": { "...": "按 type 定义" },
  "usage": {"input": 0, "output": 0, "totalTokens": 0, "cost": 0.0}
}
```

**与 pi 事件的映射（对接用）**

| pi 事件 | StepEvent.type |
|---|---|
| `agent_start` | （可选）`THOUGHT` 起点 / 不发 |
| `message_update.thinking_delta` | `THOUGHT` |
| `message_update.text_delta` | `SUMMARY`（流式） |
| `tool_execution_start` | `TOOL_CALL` |
| `tool_execution_end` | `TOOL_RESULT`（`isError` → `ERROR`） |
| `agent_settled` | `DONE` |

**兼容规则（IDL 纪律）**：字段只增不改不删；`type` 枚举只加不删；未知字段消费者必须忽略；
帧必须带 `v`；破坏性变更升 v2 且保留 v1 解析 ≥1 个版本。
