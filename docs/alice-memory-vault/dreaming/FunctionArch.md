# Agent 记忆系统架构设计文档（格式化精简版）
## 整体设计总纲
系统围绕**解耦、数据降维、控制论反馈闭环**三大核心思路构建，**剥离中间件物理属性**，聚焦能力抽象、数据边界、在线/离线非对称流转三大方向。

---

## 一、核心设计思想（Design Philosophy）
1. **白盒化与可审计性**
底层程序记忆支持版本化、差异比对，完整留存Agent思维链路，全程可审计、可人工干预。

2. **读写分离 & CQRS 范式**
- **在线平面**：写重读轻，高频追加预写日志，仅读取精简三层记忆状态，保障线上高性能。
- **离线平面**：读重写轻，异步批量处理原始日志，通过大模型完成数据降维，原子更新状态。

3. **空间换时间、离线承接在线**
将大模型高耗时的上下文过滤、反思重构等逻辑迁移至离线`Dreaming`机制，缩减在线推理开销与上下文窗口压力，保证在线Agent轻量运行。

**流转链路**：

3. 离线引擎异步消费日志，启动幻梦管线处理
4. 处理结果原子回写至三层记忆舱，完成闭环

## 三、模块设计与核心职责
### 1. 执行平面（Online Execution Plane）
#### ContextAssembler 上下文组装器
- 定位：在线运行时入口、RAG聚合网关
- 职责：不从原始日志取全量数据，按需拉取三层记忆，拼接为精简Prompt对外输出。

#### WalSession 预写日志处理器
- 遵循 **WAL 预写日志** 规范
- 职责：Agent所有思考、动作、观测结果先落日志；系统异常时可通过日志重放，完整恢复运行上下文。

### 2. 三级记忆矩阵（Memory Vault Matrix）
三层记忆共同构成Agent**动态世界模型**：
#### Episodic Vault 情节记忆舱
- 存储：会话时间线、单会话步骤快照
- 特性：具备数据衰减能力，老旧会话数据由离线机制持续压缩清理。

#### Semantic Vault 语义记忆舱
- 存储：跨会话网状事实、用户偏好、通用知识
- 特性：打破会话隔离，实现全局知识关联与理解。

#### Procedural Vault 程序记忆舱
- 存储：强类型规则、标准化作业流程(SOP)、工具调用链路
- 特性：Agent固化的执行范式，行为优先级最高，保证动作确定性。

### 3. 进化平面（Offline Dreaming Engine）
系统自主进化核心，由三级流水线组件组成：
#### PromptMelter 熔炼器
- 定位：数据降维过滤器
- 职责：清洗预写日志冗余内容，提炼核心有效信息，大幅压缩数据体量。

#### Conflict Resolver 冲突消除器
- 定位：知识图剪枝引擎
- 职责：识别新旧知识冲突、过期信息，执行剪枝与覆盖，避免大模型因矛盾上下文产生幻觉。

#### Crystallizer 结晶器
- 定位：模式识别器
- 职责：从多轮会话中提炼高频、稳定的执行模式，固化为SOP写入程序记忆舱。

## 四、控制论反馈闭环（Cybernetics）
### 闭环模型
```text
[输入指令] → Agent决策执行 → 调用工具影响环境
                ↑                    ↓
        三层记忆数据       原始状态变更（WAL日志）
                ↑                    ↓
        幻梦引擎复盘沉淀 ← 离线消费日志
```

### 链路说明
1. **前向控制（在线）**：Agent依托已有记忆完成决策执行，全流程轨迹落地WAL日志。
2. **后向反馈（离线）**：系统空闲/定时启动幻梦引擎，复盘日志并将有效经验沉淀为新记忆。

### 设计价值
代码层面模块解耦清晰，工程易维护；理论层面实现**低成本、高可靠、可自主进化**的工业级Agent落地方案。
