## 三、四层工具闭环标准运行流程
具备四层完整工具栈后，Agent 标准任务执行链路：
1. **接收用户任务**
   用户提问包含实时资讯、前沿技术、线上动态等本地库无覆盖信息
2. **外部感知补全信息**
   Agent 判断本地数据不足，调用 `web_search` 获取全网最新结构化资料
3. **本地持久化存储**
   解析检索结果，通过 `write_file` 将外部数据落地本地文件留存
4. **本地校验+脚本执行**
   使用 `list_dir`/`search_file` 校验本地文件依赖，最终通过 `run` 执行本地业务脚本

## 四、架构设计总结
整套工具集分层解耦清晰：底层提供原子化文件读写、遍历能力；中层支撑文本检索、系统命令执行；顶层扩展外网实时信息获取，形成完整自闭环数据处理链路。
