## 5. 已知问题（待优化）

- [!] LLM 行为：即使 system prompt 明确禁止重复读 + 代码层拦截返回 `[CACHED]`，DeepSeek 仍然在每个 turn 发出相同的 5 个 `read_file` 调用，直到 depth=30 熔断  [root_cause:: LLM behavioral issue, not code issue]
- [!] 建议方向 1：改进 system prompt 更强制地要求 LLM 直接回复  [status:: pending]
- [!] 建议方向 2：深度计数时跳过 `[CACHED]` 的 tool call 不消耗 depth  [status:: pending]
- [!] 建议方向 3：同一文件被请求 N 次后返回更强硬的终止提示  [status:: pending]
